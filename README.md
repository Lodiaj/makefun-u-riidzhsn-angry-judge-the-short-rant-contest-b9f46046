One short, funny rant about a small everyday annoyance: the smoke detector
that only ever needs a new battery at 3 a.m.

## Run

```sh
node main.ts
```

The program writes the rant to `/output/entry.txt` (UTF-8, 1–400 characters,
inside the gate), and prints the character count.
